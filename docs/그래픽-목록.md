# 그래픽 파일 목록

기획서 7-2 기준으로 필요한 그래픽 전체 목록입니다. 만들면 `src/assets/images/`에 넣고 체크해 주세요.
파일이 없으면 게임은 이름 글자(예: "포크")를 임시로 띄우기 때문에, 순서와 상관없이 하나씩 넣어도 됩니다.

- 형식: 아이콘·도구·마늘은 **SVG**, 사진풍 그림(메뉴)은 **WebP**(또는 PNG)
- 용량: 파일 하나 **200KB 이하**
- 이름: `대상-상태.확장자`. `src/config.js`의 `image` 값과 같아야 합니다
- 같은 종류끼리는 **캔버스 크기와 기준점을 맞춰** 주세요(교체될 때 그림이 튀지 않게)
- AI로 만들었다면 PR에 도구 이름을 적어 주세요
- 파일이 없는 동안에는 `index.html` 안의 임시 그래픽(`<symbol>`)이 보입니다. 같은 이름의 파일을 넣으면 자동으로 바뀝니다(svg → webp → png 순서로 찾음)

## 도구 (6)

도구는 세 겹으로 쌓습니다: **뒤판(`-back`) → 마늘 → 앞판(`-front`) → 움직이는 부분(이름 그대로)**.
움직이는 부분은 칠 때마다 흔들리거나 내려찍는 연출이 붙습니다.

| 도구 | `-back` (뒤판) | `-front` (앞판) | 이름 그대로 (움직이는 부분) |
|---|---|---|---|
| 자동 믹서기 | 유리 용기 + 모터 받침 | 유리 앞면 | 뚜껑 |
| 수동 믹서기 | 유리 볼 | 유리 앞면 | 손잡이 달린 뚜껑 |
| 절구 | 절구 안쪽 | 절구 앞면 | 절굿공이 |
| 칼과 도마 | 도마 | (없음) | 칼 |
| 맨주먹 | 도마 | (없음) | 주먹 |
| 포크 | 도마 | (없음) | 포크 |

위치와 크기는 `src/style.css`의 `.comp[data-tool="…"]` 에서 맞춥니다.
