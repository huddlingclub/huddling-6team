# 기획서 — 오늘도 다짐

팀 공통 기준 문서입니다. 바꾸고 싶은 내용이 있으면 **이 파일을 수정하는 PR**을 올려 주세요.

> 상태: **v1.4** (FAIL 화면 메뉴 표시, 팝업 단축·탭으로 넘기기) · 게임 이름 **오늘도 다짐** (확정)
> 핵심 숫자는 **6**입니다. 우리 팀이 6조라서 레벨 6단계, 한 판 최대 6쪽, 하루 6판으로 정했습니다.

## 1. 한 줄 기획

퇴근길에 쌓인 화를 마늘에 풀고, 끝까지 다진 만큼 오늘의 저녁 메뉴를 받는 게임.

| 항목 | 내용 |
|---|---|
| 게임 이름 | 오늘도 다짐 — '마늘을 다지다'와 '오늘도 다짐한다'를 겹친 말장난 |
| 타깃 | 화가 많이 쌓인 직장인. 짧은 쉬는 시간이나 퇴근 직후에 30초~1분 정도 플레이 |
| 감정 | "속 시원함" → "오늘 저녁 뭐 먹지" 고민이 해결됨 → 친구와 순위 경쟁 |
| 플랫폼 | 모바일 웹 우선(터치). PC에서는 스페이스바로 플레이 |

## 2. 핵심 루프

```
홈(오늘 n/6판) → 판 시작
 → [미션 팝업 → 제한시간 안에 마늘 1쪽 패기 → 클리어(점수 팝업)] × 레벨 1~6
     └ 제한시간 초과 = FAIL(여기까지 깬 레벨 기준 메뉴 표시) → 친구에게 메뉴 공유하면 한 번 더(판당 1회) / 아니면 종료
 → 결과 화면에 메뉴 바로 표시(도달 레벨 기준 랜덤) → 점수·이번 달 순위
   (첫 판이면 닉네임 자동 생성 + 바꾸기)
 → 이미지 저장(메뉴 카드) / 친구에게 공유 → 다시 하기 또는 리더보드
```

- **한 판** = 레벨 1~6을 연달아 깨는 스테이지입니다. 레벨 하나에 마늘 1쪽이라서, 끝까지 깨면 6쪽이 됩니다.
- **하루 제한**: 하루에 6판까지 플레이할 수 있습니다. 판을 시작할 때 1판이 줄어들고, 자정(한국 시간)에 다시 채워집니다.

### 2-1. 조작

| 기기 | 다지기 | 그 밖의 버튼 |
|---|---|---|
| 모바일 | 마늘을 터치 | 버튼 터치 |
| PC | 스페이스바 | 마우스 클릭 |

- PC 조작은 스페이스바 하나로 단순하게 유지합니다.
- 스페이스바를 꾹 누르고 있어도 1번만 인정합니다. 연타해야 손맛이 납니다.

### 2-2. 레벨별 도구 6종 — 레벨이 오를수록 패기 어려운 도구

| 레벨 | 도구 | 1쪽당 탭 수 | 제한시간 | 소리(글자 연출) | 패는 맛 | 화 해소량 |
|---|---|---|---|---|---|---|
| 1 | 자동 믹서기 | 12 | 6.0초 | 위이이잉— | 가볍게 손 푸는 몸풀기 | 12 |
| 2 | 수동 믹서기 | 18 | 6.6초 | 드르륵 드르륵 | 손잡이를 돌리듯 연타하는 맛 | 15 |
| 3 | 절구 | 24 | 7.2초 | 쿵! 쿵! | 한 방 한 방이 묵직함 | 17 |
| 4 | 칼과 도마 | 30 | 7.8초 | 탁탁탁 | 리듬감 있게 정성껏 다지는 맛 | 18 |
| 5 | 맨주먹 | 36 | 8.4초 | 퍽! 퍽! | 직접 패는 쾌감이 최고. 화면이 크게 흔들림 | 20 |
| 6 | 포크 | 42 | 9.0초 | 콕! 콕! | 찔러도 찔러도 안 다져지는 극한의 인내. 최종 보스 | 25 |

- 원칙: 많이 패야 하는 도구일수록 화가 더 많이 풀립니다.
- 제한시간은 레벨마다 0.6초씩 늘어납니다(6~9초). 탭 수는 레벨마다 6탭씩 늘어서, 필요한 속도가 레벨 1의 초당 2.0회에서 레벨 6의 초당 4.7회까지 올라갑니다. (v1.4.3: 레벨 1~3이 몇 번만 쳐도 끝나서 탭 수를 늘림)
- 난이도 기준: 레벨 1~3은 누구나 깨고, 레벨 4부터 쉬지 않고 연타해야 하며, 레벨 6은 크리티컬 운이나 콤보가 있어야 아슬아슬하게 깨는 수준을 목표로 합니다.
- 시간은 "3·2·1" 카운트가 끝난 순간부터 잽니다. 도구 등장 연출 중에는 시간이 가지 않습니다.

### 2-3. 다져지는 단계 (1쪽 기준)

통마늘 → 반 토막 → 굵게 다짐 → 곱게 다짐 → 다진 마늘 완성(다음 레벨로)

### 2-4. 화 게이지

처음에는 100에서 시작해서 레벨을 깰 때마다 그 도구의 화 해소량만큼 줄어듭니다. 6레벨 해소량을 모두 더하면 107이라서, 끝까지 깨면 화가 100% 풀립니다. 결과 카드에는 "오늘의 화 ○% 해소"로 보여 줍니다.

## 3. 점수와 레벨업 정책

### 3-1. 레벨업 트리거

- 제한시간 안에 마지막 탭까지 끝내면 레벨 클리어입니다. 점수 팝업이 뜬 뒤 다음 레벨 미션 팝업으로 넘어갑니다.
- 제한시간 안에 못 끝내면 FAIL입니다.

### 3-2. 점수 = 속도 × 레벨 배수 × 콤보 배수 + 크리티컬

- 레벨 점수 = 내 탭 속도(초당 탭 수) × 100 × 레벨 번호 × 콤보 배수 + 크리티컬 보너스
- 한 판 점수 = 깬 레벨들의 점수 합계 + 6레벨을 모두 깨면 보너스 1,000점
- 탭 속도 = 그 레벨의 탭 수 ÷ 걸린 시간(초)
- 콤보 배수 = 그 레벨에서 도달한 최고 콤보 구간의 배수 (3-3 참고)
- 예: 레벨 6(포크 32탭)을 6.4초 만에 깨고(초당 5회) 최고 30콤보(×1.3)에 크리티컬 2번이면 5 × 100 × 6 × 1.3 + 2 × 300 = 4,500점
- 실패한 레벨은 0점입니다.

### 3-3. 연타 콤보와 크리티컬 (후르츠 닌자 벤치마킹)

**연타 콤보**: 쉬지 않고 이어서 치면 콤보가 쌓이고, 콤보가 클수록 점수 배수가 올라갑니다.

| 콤보 | 배수 | 연출 |
|---|---|---|
| 0~9 | ×1.0 | — |
| 10~19 | ×1.1 | 10 COMBO |
| 20~29 | ×1.2 | 20 COMBO + 글자 커짐 |
| 30~49 | ×1.3 | 30 COMBO + 화면 테두리 번쩍 |
| 50 이상 | ×1.5 (최대) | MAX COMBO |

- 탭과 탭 사이가 0.3초 이내면 콤보가 이어집니다. 0.3초 넘게 멈추면 0으로 초기화됩니다.
- 콤보는 레벨이 바뀌어도 이어집니다. 점수 팝업과 미션 팝업이 떠 있는 동안은 멈춘 것으로 치지 않습니다.
- 그래서 레벨 1부터 끊지 않고 치면 높은 레벨에서 큰 배수를 받습니다.

**크리티컬**: 탭할 때마다 5% 확률로 "크리티컬!"이 터집니다.

- 점수: 크리티컬 1번마다 +50 × 레벨 번호 (레벨 6이면 +300점)
- 진행: 그 탭은 2탭으로 인정합니다. 마늘이 한 번에 더 많이 다져집니다.
- 연출: 큰 글자 "크리티컬!", 화면 흔들림, 모바일 진동

**난이도 체감 장치**: 레벨 6의 필요 속도(초당 4.7회)는 보통 사람의 연타 한계에 가깝습니다. 그래서 콤보를 유지하는 집중력과 크리티컬 운이 실제로 클리어를 가릅니다.

### 3-4. FAIL과 이어하기

- FAIL 화면에는 그때까지 깬 레벨 기준으로 뽑은 **오늘의 저녁 메뉴**(메뉴명, 한 줄 PS)가 바로 보입니다. 결과 화면까지 가지 않아도 메뉴를 받습니다.
- FAIL 화면에는 두 버튼이 나옵니다: **친구에게 메뉴 공유하고 한 번 더** / **결과 보기**
- 공유 문구에 메뉴가 들어갑니다. 예: "오늘 저녁은 감바스! 근데 LV4에서 막혔어요. 나 대신 마늘 좀 다져 줄 사람?"
- 그대로 결과 보기를 누르면 FAIL 화면의 메뉴가 결과 화면에도 그대로 나옵니다. 이어하기로 더 높은 레벨까지 가면 그 레벨 기준으로 다시 뽑습니다.
- 공유하면 실패한 레벨부터 다시 도전합니다. 그때까지 얻은 점수는 그대로 남습니다.
- 이어하기는 한 판에 1번만 가능합니다. 두 번째 실패하면 결과 화면으로 갑니다.
- 이어하기를 해도 점수 불이익은 없습니다. 하루 판 수도 줄지 않습니다.

**공유 방식 (기기별)**

- 모바일: 기기 기본 공유 바텀시트가 올라옵니다. 카카오톡, 문자, 인스타그램 등 원하는 앱을 골라 보냅니다.
- PC 웹: 게임 링크를 클립보드에 복사하고 "링크 복사 완료!" 토스트를 띄웁니다.
- 공유 인정 기준: 모바일은 바텀시트를 열면, PC는 링크 복사가 끝나면 인정합니다. 웹에서는 실제로 보냈는지 확인할 수 없기 때문입니다.
- 결과 화면의 **친구에게 공유** 버튼도 같은 방식으로 동작합니다.

### 3-5. 기타 정책

| 항목 | 정책 |
|---|---|
| 앱 이탈 | 플레이 중 화면을 벗어나면 일시정지. 돌아오면 3·2·1 후 재개 |
| 매크로 방지 | 1초에 15회를 넘는 탭은 무시하고 콤보도 끊음. config.js 값으로 계산한 이론상 최고점을 넘는 점수는 서버에서 거부 |
| 하루 6판 | 판을 시작할 때 차감. 도중에 나가도 돌려주지 않음 |
| 시연 모드 | config.js에서 하루 제한을 끄고, 횟수 초기화 버튼을 켤 수 있음 |
| 방해 요소 | 플레이 중 방해 팝업은 넣지 않습니다. ("부장님 이거 오늘까지 가능?" 같은 팝업 삭제) |
| 화면 문구 | 남은 초, 탭 수, 모자란 시간 같은 숫자 서브 멘트는 화면에 쓰지 않습니다. 시간과 진행은 막대(바)로만 보여 줍니다 |
| 팝업 시간 | 미션 팝업 2.0초, 점수 팝업 1.5초 동안 보여 준 뒤 자동으로 다음 단계로 넘어갑니다. 화면을 탭(PC는 스페이스바)하면 바로 넘어갑니다. 연타가 팝업을 바로 넘기지 않게 뜬 뒤 0.4초 동안은 탭을 받지 않습니다. 제한시간은 미션 팝업이 닫힌 뒤부터 잽니다 |

### 3-6. 한 판 길이

| 항목 | 값 |
|---|---|
| 한 판 최대량 | 6쪽 (레벨 6까지 클리어) |
| 하루 플레이 횟수 | 6판 |
| 한 판 길이 | 보통 약 55초 (탭 약 36초 + 미션 팝업 6번 12초 + 점수 팝업 5번 7.5초). 팝업을 탭으로 넘기면 더 짧아짐 |
| 하루 최대 플레이 시간 | 약 3~5분 |

근거: 6레벨 탭 수를 모두 더하면 162탭입니다. 사람이 보통 1초에 4~5번 탭한다고 가정했습니다.
모든 숫자는 `src/config.js` 한 파일에서만 고칩니다. 플레이해 보고 함께 조정합니다.

## 4. 메뉴 카드 10종 (API 없이, 랜덤)

## 5. 리더보드와 닉네임

### 5-1. 리더보드

| 항목 | 정책 |
|---|---|
| 기준 | 1인당 이번 달 최고 판 점수로 순위 |
| 초기화 | 매달 1일 0시(한국 시간) |
| 명예의 전당 | 지난달 1~3위 닉네임과 점수를 남김 |
| 동점 | 먼저 기록한 사람이 위 |
| 화면 | 이번 달 TOP 50 + 내 순위. 이어하기한 기록은 ♻ 표시(점수 불이익 없음) |
| 0점 기록 | 리더보드에 올리지 않음 |
| 기록이 없을 때 | 리더보드에 보여 줄 기록이 하나도 없으면 홈, 결과, 오늘 끝 화면의 리더보드 버튼을 숨깁니다 |

### 5-2. 닉네임

| 항목 | 정책 |
|---|---|
| 생성 시점 | 첫 판이 끝나 결과 화면이 뜰 때 자동 생성 (예: "퇴근하고싶은 마늘#0614"). 첫 진입에서는 입력을 받지 않음 |
| 결과 화면 안내 | "이번 달 랭킹 12위에 퇴근하고싶은 마늘#0614로 올라갔어요" + 닉네임 바꾸기 |
| 변경 | 결과 화면, 홈, 리더보드에서 언제든. 2~10자, 금지어 차단, 뒤의 #4자리는 유지 |

## 7. 개발 원칙

### 7-1. 공통

- 화면 방식은 버튼과 글자(DOM)로 만듭니다. 캔버스는 쓰지 않습니다. 이 게임의 핵심은 탭 횟수와 단계 변화라서 물리 효과나 프레임 애니메이션이 필요 없습니다. DOM 버튼은 터치와 접근성을 기본으로 지원합니다.
  - 예외: 메뉴 카드를 이미지로 저장할 때만 캔버스에 카드를 그려서 파일로 만듭니다.
- 속도, 점수, 시간, 횟수 같은 숫자는 `src/config.js`에만 둡니다.
- 입력은 모바일 터치, PC 스페이스바 두 가지입니다(2-1 참고).
- 외부 라이브러리는 쓰지 않는 것이 원칙이고, 빌드 과정도 없습니다. 예외는 하나뿐입니다.
  - 리더보드 서버: Supabase나 Firebase 같은 무료 서버. 라이브러리 없이 fetch로 연결하는 것을 우선으로 합니다.
- 공유는 브라우저 기본 기능(모바일 공유 바텀시트, PC 링크 복사)으로 처리하므로 카카오 SDK는 쓰지 않습니다.
- 앱 키와 서버 주소는 커밋하지 않습니다. 설정 방법은 README에 따로 적습니다.

### 7-2. 그래픽 원칙

처음부터 그래픽을 넣어서 만듭니다. 도형만으로 먼저 만드는 단계는 따로 두지 않습니다.

- **로직과 겉모습 분리**: game.js는 상태(레벨, 단계, 점수)만 바꾸고, 어떻게 보일지는 CSS 클래스와 그래픽 파일이 정합니다. 그래픽 담당이 game.js를 고치지 않아도 되게 하기 위해서입니다.
- **파일 위치**: 그래픽은 `src/assets/images/`, 효과음은 `src/assets/sounds/`에 둡니다.
- **파일 이름 규칙**: `대상-상태.확장자` 형식으로 짓습니다. 예: `garlic-stage0.svg` ~ `garlic-stage4.svg`, `tool-fork.svg`, `menu-pasta.webp`
- **형식과 용량**: 아이콘과 도구는 SVG, 사진풍 그림은 WebP나 PNG로 만듭니다. 파일 하나는 200KB 이하로 맞춥니다. 모바일 로딩 속도 때문입니다.
- **그래픽이 아직 없을 때**: 해당 자리에는 이름 글자(예: "포크")를 임시로 띄웁니다. 그래픽이 늦어져도 다른 사람의 작업이 막히지 않게 하기 위해서입니다.
- **저작권**: 직접 만들었거나 상업적 이용이 허용된 그래픽만 씁니다. AI로 만든 그래픽이면 PR에 어떤 도구로 만들었는지 적습니다.

## 8. 범위

### Phase 1 — 발표용

- **필수(핵심)**: 레벨 1~6 스테이지(도구 6종, 제한시간) → 마늘 패기(터치·스페이스바) → 연타 콤보·크리티컬 → 점수 계산 → FAIL과 이어하기 → 결과 화면에 메뉴 바로 표시(10종 랜덤, API 없음) → 하루 6판 제한
- **필수(마무리)**: 결과 화면의 이미지 저장(메뉴 카드)과 친구에게 공유(모바일 바텀시트 / PC 링크 복사). 공유는 이어하기 조건이기도 해서 필수로 둡니다
- **리더보드와 닉네임**: 먼저 브라우저에 내 기록만 저장해서 순위 화면을 만들고, 서버를 붙여 팀원끼리 비교하는 순서로 진행
- **그래픽**: 처음부터 그래픽을 넣어 제작 (7-2 참고)

### 시간이 되면

- 최근 7일 기록: 날짜별 도달 레벨, 점수, 메뉴를 표시합니다. 브라우저 localStorage에 저장해서 새로고침해도 남습니다.
- 공감 답변 API: 따로 붙여 봅니다. 연결이 잘 안 되면 미리 준비한 한두 문장으로 시연합니다.
- 후속 후보: 실제 밤 시간 알림, 월간 달력, 재료에 맞춘 레시피 API. 발표 때는 버튼으로 밤 화면을 바로 열어 시연합니다.

### Phase 2 — 추가 기능

- 욕 워싱: 음성이나 채팅으로 화를 쏟아내면 순화된 문장으로 바꿔서 보여 줍니다.
- 위치 기반 맛집 추천: 추천 메뉴를 파는 근처 가게를 연결합니다.
